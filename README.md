# 🎃 2026 HALLOWEEN SURVIVAL GAME SYSTEM

## 1. 프로젝트 개요

- **목적:** 스마트 TV 전광판 화면과 호스트의 스마트폰 리모컨, 참가자의 스마트폰 지령서를 실시간으로 연동하는 웹 기반 할로윈 파티 서바이벌 게임 시스템.
- **호스팅:** GitHub Pages (정적 호스팅)
- **실시간 동기화:** Firebase Realtime Database (서버리스, `.read` / `.write` 권한 `true` 개방 상태)
- **배경 영상:** YouTube iframe 삽입 방식 (Git LFS 용량 이슈 회피 및 안정성 확보)

## 2. 화면 구성 (URL 해시 라우팅)

단일 `index.html`에서 URL 해시값(`window.location.hash`)을 통해 3개의 화면을 완벽히 분리하여 렌더링합니다.

- **📺 `#tv` (거실 TV 전광판):** 노트북을 HDMI로 연결해 전체화면으로 띄워두는 뷰. 배경 영상과 현재 스테이지 상태, 타이머 등을 출력.
- **📱 `#mobile` (참가자 지령서):** 참가자들이 QR코드를 찍고 접속하여 자신의 4자리 코드와 이름을 입력해 정체를 확인하는 뷰.
- **🛠️ `#admin` (호스트 GM 리모컨):** 호스트 전용 조종 패널. 진입 시 비밀번호(`261031`) 필요. 여기서 버튼을 누르면 Firebase를 통해 TV와 참가자 화면이 0.1초 만에 동기화됨.
